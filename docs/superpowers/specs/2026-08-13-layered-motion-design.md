# 全站分层节奏与智能章节罗盘设计

## 方向

采用已确认的 B「分层节奏」：全站共享克制、精密的 hover、press、focus 与 reveal 语言；首页、Works、Concerts 各保留一处更强的标志性交互。新增 A「智能章节罗盘」，整合章节导航、阅读进度与回到顶部，替代原有章节圆点和独立回顶按钮。

## 视觉系统

- 延续暖白纸张 / 深空蓝黑双主题，不更换字体与内容结构。
- 新增统一交互 token：悬浮抬升、媒体缩放、交互光泽、按下回落与过渡时长。
- 所有交互不改变字重、字距、换行与布局尺寸。
- fine pointer 才启用方向感与位移动效；触控和 reduced-motion 保持静态。

## 智能章节罗盘

- 桌面固定于右侧，显示圆形阅读进度、当前百分比、章节序号与标签。
- 点击进度圆回到顶部；点击章节使用原生 fragment URL，并同步 `aria-current`。
- 移动端压缩为底部悬浮条，保留当前章节、章节切换和回顶能力，不遮挡正文。
- 首页、学业、荣誉、研究、作品、演唱会使用页面专属锚点；404 不显示。

## 标志性交互

- 首页：五个小世界使用受控的指针方向光泽与边缘色带，仍最多上移 3px。
- Works：dossier 使用边缘光泽追踪，强化项目层级，不改变项目名称排版。
- Concerts：海报在已有轻倾斜基础上增加受控光泽和媒体层次，灯箱与轮播逻辑保持不变。

## 可访问性与验收

- 键盘焦点、fragment、主题切换和语义状态完整。
- reduced-motion 下取消位移、倾斜、光泽追踪和 reveal 动画。
- 320、390、768、1024、1440px 无横向溢出。
- 执行 typecheck、lint、unit、build、smoke 与完整 Playwright。
